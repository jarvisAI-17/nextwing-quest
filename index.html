So funktioniert's

Code bekommenDie Spielleitung schickt dir einen persönlichen Link mit deinem Spielcode.
Rätsel lösenHier auf der Seite: tippen, schieben, rubbeln, entschlüsseln. Tipps gibt es, wenn du feststeckst.
Gemeinsam ankommenManche Rätsel gehen nur zusammen. Am Ende bildet ihr gemeinsam den Schlusssatz.
